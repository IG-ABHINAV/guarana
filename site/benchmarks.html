How to read these numbers

  • Game fps is how many frames the game itself renders each second. Frames made by frame generation never count.
  • Verified scene means the run's scene check passed: the benchmark confirmed the game was where it claims before counting frames. A run in the wrong place is not a result, whatever its fps.
  • One laptop, one scene. Other games, scenes, drivers, power limits and machines will give other numbers.

How new results are measured

New rows come from the benchmark harness in tools/bench. It runs one game scene the same way on any machine and writes one JSON row per run: it drives the emulator through its debug server, restores the same save for every run, plays the scene's timed inputs, checks the scene against your reference screenshot and refuses to count a run in the wrong place. It needs Python 3.9 or newer and nothing else.

Baseline and change run back to back on the same machine, at least two windows each. A change that doesn't beat run-to-run spread is not a gain.
